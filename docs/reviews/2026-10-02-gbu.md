# GBU review, 2026-10-02

Good / Bad / Ugly engineering review of `flutter_voice_bridge`. Three read-only lenses looked at the code:
Dart architecture, native/FFI/build, and tests/docs/hygiene. The session checked each finding against the
code with grep, git, otool or the GitHub API before acting on it. An independent read-only checker then
re-verified every fix; its findings and what happened to them are in "Independent check" below. This file is the
baseline for the next round.

Scope agreed with Esra: Tier 1 (truth and hygiene) and Tier 2 (real bugs) in three PRs. Tier 3 was
deliberately left out (see the end of this file).

## Good (keep)

1. HomeCubit gets its audio, transcription and memo services as constructor-injected abstractions. That is
   what makes the cubit unit-testable with mocktail and bloc_test.
2. FFI memory ownership is explicit. `toNativeUtf8` is freed in `finally`. The C side pairs `new[]` with
   `delete[]` through `whisper_ffi_free_string`. No C++ exception crosses into Dart.
3. iOS and macOS record 16 kHz mono 16-bit PCM WAV, which is what Whisper expects. The C++ WAV reader
   walks chunks.
4. Microphone permissions are declared on every platform, and the native recorders report failures as
   FlutterError codes (made consistent across platforms in this round).
5. States are immutable and Equatable. The Gemma module is split by feature (data, domain, ui).
6. `AudioConverter` runs only allowlisted commands.
7. Pushed history holds no binaries and no secrets.
8. The December 2025 WIP fixed a `BuildContext`-after-await bug and named three magic numbers.

## Rejected

- "Stopping SoX with SIGTERM truncates the WAV header" (raised for the sibling repo esra-whisper-recorder).
  A recording stopped that way has a valid header, so `kill` stays.
- B1 was partly stale: main's "delete all recordings" commit had already routed most emits through the copy
  helper. Only the error paths dropped the list. The refactor fixed it anyway, together with N6.
- B6, "a model change never reaches GemmaCubit": the chat screen calls `resetChat()` when settings close. The
  rest of B6 (duplicated persistence, missing `mounted` checks) was real and is fixed.
- B8, "delete the unused AudioConverter methods": kept. `convertToWav` is the module's `Process.run` teaching
  example and the path Android's m4a recordings need before Whisper can read them.
